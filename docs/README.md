구현을 시작할 때는 실행 계획의 첫 미완료 단계와 그 단계가 참조하는 명세를 읽는다. 용어 정의는 용어집, 평가 공식은 평가 명세에만 둔다. 계획 문서에 계약을 다시 복사하지 않는다.

다음 작업을 맡을 때는 실행 계획 → P3 상세 계획 → 해당 항목의 분석 근거 순서로 읽는다. 과거 관측과 검증 결과는 분석 보고서에 보존하고, 앞으로 할 일과 미해결 검토 상태는 계획에서 관리한다. 본문 해석이 필요한 사람 검토와 코드 계약의 최소 재현을 구분한다.

장면 데이터 버전, 실행 결과 형식 버전, 평가 지표 버전은 별개다. 현재 `scenes-v3-*.json`도 장면 형식 v2를 사용한다. `run-v2-*` 파일 이름만으로 데이터나 평가 방식의 버전을 판단하지 않는다.

설계의 시작점은 `11c6ec5`이며 P1/P2 구현 상태를 반영했다. 기존 README의 실험 수치는 당시 평가 방식의 역사적 결과이며, 새 평가 방식의 결과로 덮어쓰지 않는다.
