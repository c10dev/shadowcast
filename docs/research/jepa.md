# JEPA 연구 노트

상태: 연구 제안. 조사 기준일: 2026-11-14. Shadowcast에 JEPA 구현이나 학습된 체크포인트는 없다.

## 질문

본문에서 사건·상태를 복원하는 학습에 잠재 표현 예측 목적을 더하면, 같은 자원을 쓴 지도학습 추출기보다 오류 위치 검출·헛경보·비용이 개선되는가?

이 질문을 제품 도입 판단으로 연결한다. 표현의 유사도나 영상 벤치마크 점수가 높다는 사실만으로 소설의 물리 연속성 검사를 잘한다고 결론 내리지 않는다.

## 확인한 연구

| 연구 | 확인한 내용 | 적용할 때의 한계 |
|---|---|---|
| [I-JEPA, 2023](https://arxiv.org/abs/2301.08243) | 같은 이미지의 문맥에서 가려진 영역의 표현을 예측 | 미래 예측만을 뜻하지 않으며 한국어 본문 검사 결과가 아님 |
| [V-JEPA, 2024 공식 구현](https://github.com/facebookresearch/jepa) | 영상의 시공간 표현을 자기지도 학습 | 텍스트 입력을 현재 사건 스키마로 바꾸는 추출기가 아님 |
| [V-JEPA 2, 2025](https://arxiv.org/abs/2506.09985) | 대규모 영상 학습과 행동 조건부 후학습을 이용한 예측·계획 | 로봇 행동 데이터와 시각 관측에 기반하며 직접적인 소설 적용 근거는 없음 |
| [LeJEPA, 2025](https://arxiv.org/abs/2511.08544) | SIGReg를 이용해 표현 붕괴를 제어하는 학습 목적 제안 | 학습 안정화 방법의 후보이며 물리 모순 판정기를 제공하지 않음 |
| [VL-JEPA, 2025/2026](https://arxiv.org/abs/2512.10942) | 시각 입력으로 목표 텍스트의 임베딩을 예측 | 시각·언어 과제와 텍스트만의 장면 추적은 입력·평가가 다름 |
| [V-JEPA 2.1, 2026](https://arxiv.org/abs/2603.14482) | 이미지·영상의 세밀한 공간·시간 표현 개선 | 세부 표현 향상이 손·소유·접촉의 정확한 구별을 보장하지 않음 |

[I-JEPA 방법 설명](https://arxiv.org/html/2301.08243v3)에 따르면 문맥 인코더와 예측기가 목표 인코더의 표현을 예측한다. 목표 인코더는 이동평균으로 갱신된다. 모든 JEPA 변형이 같은 손실이나 목표 인코더 갱신법을 쓰는 것은 아니다.

## 최근 연구가 제기하는 질문

- [The JEPA Paradox in Language, 2026-07](https://arxiv.org/abs/2607.23531)는 결정적 제곱오차 예측이 여러 가능한 언어 완성을 하나로 압축할 때 생기는 문제를 분석한다. 모든 텍스트 JEPA의 불가능성을 입증한 것으로 해석하지 않는다.
- [Proving and Improving the Platonic Representation Hypothesis with JEPAs, 2026-10](https://arxiv.org/abs/2610.39302)는 같은 장면의 적절한 관측 쌍으로 텍스트 표현 정렬이 개선된다고 보고한다. 이론의 조건과 실험 범위를 따르는 주장이고, 소설 모순 검출을 직접 검증한 결과는 아니다.
- [When Does Latent Prediction Error Support Physical Surprise Claims in Video World Models?, 2026-11](https://arxiv.org/abs/2611.01815)는 외양과 예측 난이도도 잠재 예측 오차에 영향을 주며, 불가능한 사건의 오차가 더 작을 수 있음을 보고한다. 예측 오차에 고정 임계값을 적용해 모순을 판정하는 설계는 별도 검증이 필요하다.

이 연구들은 서로 다른 목적·데이터·모델을 다룬다. 최근 논문의 개별 실험 결과를 전체 JEPA 계열의 확정된 성질로 일반화하지 않는다.

## Shadowcast에 대한 적용 가설

현재 시스템은 명시적인 상태와 사람이 작성한 전이 규칙을 사용한다. JEPA 계열은 표현과 예측 관계를 데이터에서 학습한다. 연결할 후보는 본문에서 사건·상태를 복원하는 학습 단계다.

첫 가설은 다음과 같다.

> 명시된 행동 이전의 문맥과 그 행동으로부터, 행동 이후의 물리 상태 표현을 예측하도록 학습하면 상태 복원이 개선될 수 있다.

이것은 새 연구 제안이며 기존 논문의 입증된 결과가 아니다. 뒤에 어떤 행동이 나올지 맞히는 것과, 주어진 행동이 앞 상태와 양립하는지 판단하는 것을 구분한다.

학습 쌍에는 같은 물리 상태를 다른 문장으로 쓴 예를 사용할 수 있다. 다만 좌우 손, 소유자, 부정, 접촉 유무, 사건 순서가 달라진 문장을 같은 상태로 묶으면 검출에 필요한 차이를 지울 수 있다. 정상판과 오류판은 자동으로 같은 의미의 양성 쌍이 되지 않는다.

정답 상태를 직접 감독하거나 모순 쌍을 구분하는 손실을 추가한다면 자기지도 JEPA만의 효과라고 부르지 않는다. 어떤 감독 정보를 사용했는지 명시하고 그 정보를 동일하게 받은 기준선과 비교한다.

## 연구 진입 조건

다음 조건이 충족될 때 실험을 시작한다.

1. [평가 명세](../evaluation.md)의 실패·위치·헛경보 지표가 구현되어 있다.
2. 사건 추출 오류와 규칙 해석 오류를 구분한 원인표가 있다.
3. 평가 장면과 겹치지 않는 별도 학습 데이터 및 출처·분할 정책이 있다.
4. 같은 데이터로 학습한 지도학습 추출기의 결과가 있다.
5. 학습·추론 자원과 실행 범위를 정했다. 영상 모델의 사전학습 전체를 재현하는 계획은 전제하지 않는다.

## 최소 비교 실험

| 구성 | 역할 |
|---|---|
| A 직접 판정 | 실제 사용 성능·비용의 기준선 |
| 지도학습 사건/상태 추출기 + 같은 규칙 판정기 | 학습된 추출기의 기준선 |
| 같은 추출기에 잠재 상태 예측 목적 추가 + 같은 규칙 판정기 | JEPA 관련 목적의 추가 효과 측정 |

학습 데이터, 초기화, 모델 규모, 분할, 튜닝 예산, 규칙 구현을 가능한 한 맞춘다. 잠재 예측 목적만 제거한 비교 실험을 포함하고, 비용이 다르면 실제 사용 비용과 학습 비용을 따로 보고한다.

평가에는 긴 거리 상태 유지, 이름 바꾸기, 패러프레이즈, 좌우·소유자·접촉의 최소 변경을 포함한다. 단순 표현 유사도 외에 상태 복원, 정답 문장 검출, 헛경보, 근거 타당성을 측정한다.

처음에는 잠재 오차를 그대로 사용자 경고로 사용하지 않는다. 명시적 상태 판정과 동일한 평가 계약을 거쳐 개선 여부를 확인한다. 여러 가능한 상태가 남는 경우를 단일 정답 벡터로 강제하는 학습이 문제를 일으키는지도 점검한다.

추가 이득이 없거나 세부 물리 차이를 잃어 헛경보·누락이 늘면 연구를 제품 경로와 분리한다. 영상·3D 생성이나 별도 시뮬레이터 도입은 이 최소 실험의 전제가 아니다.
